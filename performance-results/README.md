# Hardware performance results

Fidelity-kit reports for three-ssr-fidelity workloads, grouped by machine and session. Runs disable vsync and frame caps, warm up, measure sequentially and count GPU-completed frames.

Existing sessions cover the initial baseline and path tracer. New renderer definitions are available in the opt-in experiments collection; fidelity captures alone do not establish their performance. Preserve adapter metadata and use isolated GPU runs for final performance claims.
